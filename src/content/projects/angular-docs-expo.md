## Descripción

El requisito de la exposición era presentar un framework con una documentación hecha en ese mismo framework. El sitio usa componentes standalone y signals, carga cada página de forma diferida y se prerenderiza con SSR.

## Temas

1. Instalación y estructura del proyecto
2. Componentes y sintaxis base
3. Props y comunicación entre componentes
4. Estado y reactividad
5. Ciclo de vida
6. Routing y navegación
7. Consumo de APIs
8. Estado global
9. Ecosistema y rendimiento
10. Server-side rendering (SSR)

Cada tema incluye demos en vivo, como un reloj y un botón de "me gusta" con signals, y una cita aleatoria obtenida de DummyJSON con `httpResource`.
